API reference

Families and dispatch functions

Use an unnamed family type at each tagged argument position. For example, @turbodispatch f(::Left, offset::Int, ::Right) selects a method using both tags and forwards offset.

TurboDispatch.@dispatchfamily — Macro
@dispatchfamily Family [hot=(CommonType, AbstractGroup)]

Inputs

  • Family — an abstract type, an inline abstract type declaration, or a union.
  • hot — optional priority types or groups. Use () to clear priorities.

Outputs

  • The declared family type.

Discover concrete members and rebuild prepared overloads while preserving existing tags.

TurboDispatch.@turbodispatch — Macro
@turbodispatch f(::Family, extra::ExtraType)
@turbodispatch result = f(x::Family, extra::ExtraType)
@turbodispatch :lazy f(::Family)::ReturnType

Inputs

  • f — the function to prepare.
  • ::Family or x::Family — a tagged argument from a declared family.
  • extra::ExtraType — an ordinary positional argument.
  • :lazy — optional first-use compilation on Julia 1.13.3 for Linux x86-64, at runtime.
  • ::ReturnType — optional result type assertion.

Outputs

  • A prepared callable or, in assignment form, the result of the call.

Install overloads that let the function accept tagged arguments. In assignment form, annotations naming declared families select the tagged arguments. Other arguments pass through. Define the function and declare its families before the caller.

Tagged values

TurboDispatch.tagged — Function
tagged(Family, value)
tagged(Family, array)

Inputs

  • Family — the declared family type.
  • value — a family member, or array — an array of members.

Outputs

  • A TaggedArg{Family} or ordinary array of tagged values.

Attach family-local tags for reuse across dispatch calls.

TurboDispatch.TaggedArg — Type
TaggedArg{A}

Inputs

  • A — the declared family type.

Outputs

  • A value carrying its payload and family-local tag.

Construct a tagged argument with tagged.

TurboDispatch.raw — Function
raw(value)
raw(array)

Inputs

  • value — a tagged value, or array — an array of tagged values.

Outputs

  • The original payload or an array of payloads with the same shape.

Unwrap values tagged with tagged.

Use tagged to wrap a family member and raw to recover the original value.

const NumberPair = Union{Int,Float64}
@dispatchfamily NumberPair
value = tagged(NumberPair, 7)
raw(value)

Updating a family

After adding or changing methods, run @dispatchupdate Family outside concurrent dispatch calls. Existing tags stay valid.

TurboDispatch.@dispatchadd — Macro
@dispatchadd Type
@dispatchadd struct Member <: Root ... end

Inputs

  • Type — an existing type or an inline type declaration.

Outputs

  • nothing.

Register the type with all matching declared families and rebuild prepared overloads.

TurboDispatch.@dispatchupdate — Macro
@dispatchupdate [Family]

Inputs

  • Family — the family to rescan. Omit it to rescan all families.

Outputs

  • nothing.

Discover new members and rebuild prepared overloads outside concurrent dispatch calls.

Given a declared Signal family, use @dispatchadd to register Step immediately. Define Ramp separately and discover it with @dispatchupdate.

@dispatchadd struct Step <: Signal end
struct Ramp <: Signal end
@dispatchupdate Signal
